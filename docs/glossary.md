# Glossary

| Term | Definition |
|------|------------|
| Data-centric AI | Emphasis on improving datasets, labels, and evaluation loops rather than only scaling models. |
| Knowledge distillation | Train a small student model to mimic a larger teacher (often softer probability targets). |
| Quantization (QAT / PTQ) | Reduce numerical precision (e.g. FP32→INT8); **PTQ** is post-training, **QAT** folds quantization into training. |
| SHAP | SHapley Additive exPlanations; attributes predictions to features via cooperative game theory–inspired sums. |
| Tiny ML | ML on severely constrained devices (microcontrollers, minimal RAM/flash, strict power budgets). |
| XAI | Explainable AI; methods and metrics for human-understandable model behavior—distinct from raw accuracy. |
